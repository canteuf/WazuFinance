# Avatars de profil

Seize visages, `a01.png` à `a16.png` (256 px, fond transparent), choisis par identifiant dans les paramètres du compte et enregistrés dans `users.avatar`.

Ils sont dessinés par le style **Avataaars** de [DiceBear](https://www.dicebear.com), œuvre de [Pablo Stanley](https://avataaars.com/), libre pour un usage personnel et commercial, puis rastérisés par resvg. Le réglage de chaque visage — coiffure, teinte, tenue, expression — est fixé dans `scripts/gen-avatars.mjs`, qui explique aussi comment en ajouter un.

Un identifiant ne se retire ni ne se modifie : il est peut-être enregistré dans des profils.
